# Abstract (English version)

This retrospective study included 294 patients with treatment-resistant depression to evaluate whether pre-treatment resting-state EEG alpha power predicts response to electroconvulsive therapy.

231 patients entered the per-protocol analysis (17 excluded). The response rate was 64.1%. Each standard-deviation increase in alpha power was associated with an adjusted odds ratio for response of 1.42 (95% CI 1.11–1.82). The concordance index was 0.63 and the calibration slope was 1.08.

A sensitivity analysis repeated the primary model on the full analysis set (n = 248); conclusions were materially unchanged.

The main limitations are the single-centre retrospective design and the concordance index of 0.63, which is insufficient to support individual-level clinical decision-making. In addition, **the median follow-up was 24 months**, so long-term stability is unknown.

**Keywords:** treatment-resistant depression; electroconvulsive therapy; EEG; prediction model
