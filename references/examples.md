# 正反样例

四组对照。**左边的过不了 `convergence_log.py` 或机检。**

---

## 一、修订纪要

### ❌ 不好

```
本次自查发现若干问题，已修正。
```

**没有轮次、没有维度、没有条数、没有留痕。**
下次想知道「哪一版改了什么」——无从回溯。

### ✅ 好

```markdown
| 轮次 | 维度 | 实质 | 语言 | 未查 | 回流 |
|---|---|---|---|---|---|
| R1 | D1 事实忠实 + D10 文献著录 | 3 | 7 | 12 | 0 |
| R2 | D2 曲解原意 + D6 逻辑跳跃 | 1 | 5 | 9 | 1 |
| R3 | D3 过度概括 + D10 文献著录 | 0 | 2 | 4 | 0 |
| R4 | 独立第三方审查 | 0 | 1 | 1 | 0 |

R1 发现 9 处：①第 2 段要求对方补一份他已在第 4 页说明过的材料 …
R2 ⚠️ **本轮作废**（C3）：第 3 段的修改误删了有原文依据的内容。
    该处已回滚，本轮不计入收敛序列。
R4 独立复核由第二个模型执行（隔离纪律见 `independent-review.md`）。
```

**差在**：每轮四个数都在，**作废轮明确标了作废并回滚**，
独立复核写明是谁执行的。

---

## 二、一轮里的「发现」写法

### ❌ 不好

```
第 3 段表述不够严谨，建议修改。
```

指不出位置、说不上是什么问题、给不出改法。**这条发现没法执行，也不可核。**

### ✅ 好

```
R1-②（D1 事实忠实）第 3 段第 2 句「作者未报告依从性评估」，
   与源文件第 4 页「血药浓度监测每 2 周一次」矛盾。
   → 已改为「作者报告了血药浓度监测，但未说明是否用于依从性判定」。
```

**差在**：位置（段/句）+ 与什么矛盾（源文件哪一处）+ 改成了什么。

---

## 三、自查 vs 独立复核

### ❌ 不好

```
本轮由我自己再通读一遍，同时起到了独立复核的作用。
```

**自查不能冒充独立复核。** 没有独立执行者就标「独立复核未执行」并停止——
自己再看一遍没有引入任何新视角，C1a 会以「通过」的形态被误判。

### ✅ 好

```
本轮独立复核：**未执行**（无第二执行者）。
→ 按纪律停止，不判收敛。
```

或：

```
本轮独立复核：由第二个模型执行。输入仅含交付文本与源文件，
  **不含我的修订纪要**——避免它顺着我的判断走。
```

---

## 四、收敛判定

### ❌ 不好

```
跑了四轮，最后一轮只改了 1 处，可以收敛了。
```

三处错：只看修正数（没看是实质还是语言）；**没看 C2 未查项**；
**没看 C3**——而 C3 是「假收敛」的典型来源。

### ✅ 好

```bash
$ python scripts/convergence_log.py 自查记录.md

  R1        3    7   12    0   ❌ 未过
  R2        1    5    9    1   ⛔ 作废
  R3        0    2    4    0   ❌ 未过
  R4        0    1    1    0   ✅ 通过

  ⚠️ 1 轮因 C3 作废——作废的轮次不算「又跑了一轮」。
  ✅ 收敛：末轮 R4 四条同时成立。
```

**差在**：四条**同时**看；作废的轮次被摘出序列；
「跑了几轮」与「跑成了几轮」是两件事。
